# Corgi VPN

App web gratuita con mascota corgi animada.

## Si ves pantalla en blanco en Vercel

Falta el archivo principal completo. Subí el `index.html` autocontenido desde el proyecto local (carpeta `artifacts/tango-vpn`) o el tar `corgi-vpn-for-github.tar.gz`.

## Local

```bash
node server.js
# http://localhost:3000
```

## Vercel

Framework: Other. Sin build command. Root del repo.
